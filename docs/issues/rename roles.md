today in config and code we call the team "roles" and the team member "role"
example: roleheader.vue and rolepannel.vue

but actually the wording should be "squad" for the entire team and
"SquadMember" for one agent

because we could imagine one day to have multiple squad members of same role "coder"

valid exception: "role prompts".
that makes absolutely sense because even if we have 2 coders we will not duplicate the 
initial prompt (agent file)

==> adapt the naming consistently in the code base
